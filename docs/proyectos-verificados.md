# Recursos y enlaces verificados — 3 octubre 2026

Sparta usa su icono original (`desktop/frontend-spartan/public/favicon.png`) y las capturas `docs/assets/sparta-permisos.png` y `sparta-contexto.png` del [repositorio](https://github.com/Naiker12/Sparta-Agent). La imagen principal se capturó en la [demo interactiva publicada](https://naiker12.github.io/Sparta-Agent/#producto), con datos de ejemplo. La aplicación completa se descarga para escritorio.

AUTEM usa `public/favicon.svg` del [repositorio](https://github.com/Naiker12/AUTEM) y una captura de su [sitio público](https://autemarquitectura.com/). GitHub Pages redirige a ese dominio. La web advierte que el recorrido 360° está en preparación; no se presenta como una función ya disponible.

DragonBall usa `src/assets/img/logo.png` original. Su [URL raíz](https://naiker12.github.io/dragolBall-ionic-angular-ionic-taller/) carga y redirige a `/dragol-ball`; la URL profunda devolvió 404 en la verificación HTTP, por eso el botón utiliza la raíz.

[Mercado Express](https://naiker12.github.io/ionic-angular-fakestore-ecommerce/) responde HTTP 200 con el título del proyecto. Los repositorios de Call Connect y Gallery no anuncian GitHub Pages. Sus favicons disponibles son el símbolo genérico de Ionic, por lo que conservan iconos diferenciados del portafolio.

Los endpoints públicos de `Naiker12/portal-datos-abiertos` y `Naiker12/Tienda-virtual` devuelven 404. Sus fichas muestran el estado y omiten el botón de código hasta tener un enlace público disponible. El sistema no distingue entre repositorio privado, eliminado o renombrado.

Las funciones aparecen en Detalles y las tecnologías en ambas vistas. La galería de Sparta conserva la captura seleccionada al recargar. Los enlaces de demostración y de presentación en video se distinguen del código fuente.
